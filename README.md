# TGmap

Telegram-бот для сканирования открытых портов и определения сервисов — мини-аналог Nmap, работающий прямо в Telegram. Не требует установки внешнего Nmap: сканирование выполняется встроенным сканером на чистом Python (sockets).

## Возможности

- ⚡ **Быстрое сканирование** — проверяет порты 80, 443 (ответ за пару секунд)
- 🔎 **Полное сканирование** — порты 1–1000
- 🌐 **Топ-порты** — 22 популярных порта (SSH, HTTP, MySQL, RDP, Redis и др.)
- 📋 **Сервисы + баннеры** — определение сервиса и чтение баннера (версия ПО, имя хоста)
- 🔍 **Сканирование одного порта** — указанный IP/домен + порт
- 🗂 Хранение пользователей в SQLite

## Технологии

- **Python 3.10+**
- **aiogram 3** — Telegram Bot API
- **SQLAlchemy + aiosqlite** — асинхронная БД
- **sockets / concurrent.futures** — параллельное сканирование (свой сканер, Nmap не нужен)

## Структура


## Установка

1. Клонируйте репозиторий и перейдите в каталог:

```bash
git clone <repo_url>
cd tgmap
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Укажите токен бота. Сейчас токен задан в `run.py` напрямую — для запуска на сервере лучше вынести его в переменную окружения:

```python
# run.py
import os
bot = Bot(token=os.getenv("BOT_TOKEN"))
```

```bash
set BOT_TOKEN=ВАШ_ТОКЕН   # Windows
export BOT_TOKEN=ВАШ_ТОКЕН # Linux
```

4. Запустите:

```bash
python run.py
```

## Использование

1. Напишите боту `/start`
2. Выберите тип сканирования
3. Введите IP-адрес или домен (например `8.8.8.8`, `scanme.nmap.org`)
4. Для сканирования порта — выберите «Сканировать порт» и укажите номер

## Безопасность (для запуска на сервере)

- Разрешено сканирование **только одиночного IP/домена** — подсети (/24 и т.п.) отклоняются
- Ограничены потоки (до 50) и таймаут, чтобы не перегружать сервер
- В БД сохраняется только таблица пользователей — история сканирований не копится

## Важно

Запускайте сканирование только для своих хостов или с разрешения владельца.
